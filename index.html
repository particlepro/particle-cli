particle

Podcast intelligence from your terminal. A command-line interface for the Particle API.

macOS and Linux

curl -LsSf https://cli.particle.pro/install.sh | sh

Homebrew

brew install particlepro/tap/particle

Windows

powershell -ExecutionPolicy Bypass -c "irm https://cli.particle.pro/install.ps1 | iex"

Then

particle auth login   # key from https://platform.particle.pro/tokens
particle              # common commands and examples

All releases and checksums
